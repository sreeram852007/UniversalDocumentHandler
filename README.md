# 📄 Universal Document Handler

**A free, professional document viewer, editor, and converter for Windows**

[![Python](https://img.shields.io/badge/Python-3.14-blue.svg)](https://python.org)
[![PyQt6](https://img.shields.io/badge/PyQt6-6.5.0-green.svg)](https://pypi.org/project/PyQt6/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## ✨ Features

- 📄 **PDF Viewer** - Adobe-like interface with annotation tools
- 📝 **Word Editor** - MS Word-like rich text editing
- 📊 **Excel Editor** - Excel-like spreadsheet with formulas
- 🖼️ **Image Editor** - Basic image editing and filters
- 🔄 **File Conversion** - Convert between 15+ file formats
- 🎯 **100+ File Formats** supported
- ⌨️ **Keyboard Shortcuts** - Ctrl+Scroll to zoom, F11 full-screen
- 🆓 **100% FREE** - No subscriptions, no limitations!

## 🚀 Quick Start

### Option 1: Download EXE (No Python required)
Download from [Releases](https://github.com/sreeram852007/UniversalDocumentHandler/releases)

### Option 2: Run from Source

`ash
git clone https://github.com/sreeram852007/UniversalDocumentHandler.git
cd UniversalDocumentHandler
python -m venv venv
venv\Scripts\activate  # On Windows
pip install -r requirements.txt
python app.py
` 

## 📋 Supported Formats

| Category | Formats |
|----------|---------|
| **Documents** | PDF, DOCX, DOC, TXT, RTF, ODT |
| **Spreadsheets** | XLSX, XLS, CSV, ODS |
| **Presentations** | PPTX, PPT |
| **Images** | JPG, JPEG, PNG, GIF, BMP, WEBP, TIFF, SVG |
| **E-books** | EPUB |
| **Code** | HTML, JSON, XML, YAML, Markdown |

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| F11 | Full Screen |
| Ctrl + Mouse Wheel | Zoom In/Out |
| ← / → | Previous/Next Page |
| Home / End | First/Last Page |
| Ctrl + O | Open File |
| Ctrl + Shift + C | Convert File |
| Ctrl + S | Save |
